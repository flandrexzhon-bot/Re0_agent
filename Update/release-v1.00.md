## 🎉 首个正式版本

「Re:Zero 命运全书」v1.00 —— 一款以《Re:从零开始的异世界生活》为舞台的单机多智能体 AI 跑团 RPG，首次正式打包发布。你扮演穿越异世界的主角，由多个大语言模型智能体分别扮演 GM 与各路 NPC，一起把命运之书写下去。

## ✨ 核心特性

### 多智能体六段式大回合
- 每个大回合按 GM 开场 → 玩家抉择 → 主角行动 → 调度 NPC → NPC 依序回应 → 填表结算 六段推进。
- 回合状态机（1–6 段 + 断点编号）**算法化持久到数据库**，关掉软件重开可从断点精确继续。

### 重 roll / swipe 变体系统
- 对任意一段生成不满意都能重新 roll，像 SillyTavern 一样左右滑动切换变体。
- **完整保留本回合的全部 roll 记录**：开场记录、NPC 回复记录、填表记录都不丢。

### 时间线与回归
- **Fork / 分支时间线**：从任意历史回合分叉出平行存档。
- **死亡回归**：主角死亡后回到存档点、保留元记忆重走命运，还原原作核心设定。

### 判定与世界
- **骰子判定 + 战斗结算**：内建骰子表格与角色属性系统。
- **世界观 RAG**：内置 2MB+ Re:Zero 设定书，按场景检索注入提示词，NPC 言行贴合原作。
- **章节切换**：随剧情在原作关键章节间切换世界状态。

### 可配置的 LLM 接入
- OpenAI 兼容接口，支持 SSE 流式输出、自动重试、思考 / reasoning 模式。
- 每个智能体可在「契约之书」页独立配置端点 / 密钥 / 模型 / 温度 / 思考强度。

## 🐛 本版本修复

- **修复：填表阶段重 roll 数据被清空**。结算落库顺序改为 Save→Load，避免填表段的自动存档写入空变体后又被 Hydrate 覆盖，导致重 roll 记录（含开场 / NPC 回复 / 填表）丢失。
- **修复：主角落笔后开场重 roll 记录消失**。玩家提交抉择时不再整批清空本回合变体，仅移除将被结算版取代的那一份，其余 roll 记录全部保留；`继续`（Resume）同理只摘除中断态半成品。
- **修复：变体切换（swipe）越界导致停留在未完成回合**。前端改为在运行段（GmOpening/ProtagonistActing/NpcDispatching/NpcResponding/Finalizing）禁用 swipe，只在最新回合允许，避免切到 `CompletedAt=null` 的开场变体后卡住。
- **修复：安装后图标显示空白 / 不正确**。打包时生成的 ICO 由单一 256px 改为内嵌 16/32/48/64/128/256 多尺寸，任务栏与快捷方式的小图位置不再空白。

## 📦 安装

1. 双击 `dist/install.exe`，按向导完成安装（默认装到 `Program Files\Re0Agent`）。
2. 开始菜单 / 桌面出现「Re:Zero 命运全书」快捷方式，图标为 RE:0 星空主题。
3. 首次运行到「契约之书」页填入你的 LLM API 端点与密钥即可开局。

安装器为 self-contained，**无需预装 .NET 运行时**。存档数据库位于 `%LOCALAPPDATA%\re0agent.db`，**卸载软件不会删除存档**。

## ⚠️ 已知限制

- 目前仅 Windows 桌面版。
- 安装器未做代码签名，首次运行可能出现 SmartScreen「未知发布者」提示，选「仍要运行」即可。
- 游戏体验取决于所配置 LLM 服务的质量与上下文长度。
